# 本科毕业论文指导技能 (undergraduate-thesis)

Claude Code 技能 —— 理工科本科毕业论文全流程写作指导。

## 覆盖范围

| 阶段 | 功能 |
|------|------|
| 格式规范提取 | 上传 .docx 模板 / 指定学校名称 / 手动描述，自动提取格式规则 |
| 开题报告 | 七部分标准结构 + 任务书撰写指导 |
| 时间规划 | 从答辩日期倒推的个性化进度表 |
| 逐章写作 | 摘要→Abstract→绪论→文献综述→理论→方法→实验→结论→参考文献→致谢 |
| 学术翻译 | 60+术语中英对照 + 常见错误翻译表 |
| 文献检索 | 10个数据库推荐 + 检索策略 + 效率工具 |
| 格式合规检查 | 逐项对照格式规范，输出检查报告和修正建议 |
| 查重降重 | 查重原理 + 4种降重策略 + 降重误区警示 |
| 答辩准备 | PPT结构（15页）+ 逐字稿 + 常见Q&A + 模拟答辩 |

## 使用方式

在 Claude Code 中：

- 直接说 `毕业论文` / `毕业设计` / `开题报告` / `帮我写论文` 触发
- 或输入指令：`检查格式` `写摘要` `降重这一段` `准备答辩` `答辩模拟` `找文献` `规划时间`
